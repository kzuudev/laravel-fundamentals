## Learning Roadmap

My goal is to become a software engineer proficient in Laravel
and capable of building, testing, deploying, and maintaining
full-stack applications.

### Phase 1: Strengthen Software Engineering Fundamentals

- [ ] Understand HTTP, networking basics, and the request lifecycle.
- [ ] Practice data structures and basic time complexity.
- [ ] Improve SQL, data modeling, constraints, and indexes.
- [ ] Understand transactions and data consistency.
- [ ] Write readable code with clear responsibilities.
- [ ] Strengthen debugging, error handling, and logging.
- [ ] Practice Git workflows, code reviews, and documentation.
- [ ] Understand authentication, authorization, and web security.

### Phase 2: Learn Laravel Foundations

- [ ] Understand project structure, Artisan, and configuration.
- [ ] Work with routes, controllers, requests, and responses.
- [ ] Build CRUD features using Blade.
- [ ] Use migrations, Eloquent models, and relationships.
- [ ] Implement filtering and pagination.
- [ ] Validate input with Form Requests.
- [ ] Display validation errors and preserve form input.
- [ ] Implement authentication, middleware, and policies.
- [ ] Understand dependency injection and the service container.

### Phase 3: Build Testing Skills

- [ ] Write tests using Arrange → Act → Assert.
- [ ] Distinguish unit, integration, feature, and browser tests.
- [ ] Test success, failure, permissions, and boundary cases.
- [ ] Use factories and independent test data.
- [ ] Verify database changes and transaction rollback.
- [ ] Learn mocks and fakes.
- [ ] Add regression tests for fixed bugs.
- [ ] Run tests automatically through continuous integration.

### Phase 4: Develop Full-Stack Laravel Applications

- [ ] Connect React to Laravel using Inertia.
- [ ] Handle forms, loading states, and failed requests.
- [ ] Build accessible, responsive interfaces.
- [ ] Enforce authorization on the backend.
- [ ] Understand when to use a separate frontend and API.
- [ ] Design consistent JSON responses using API resources.
- [ ] Work with notifications, jobs, and queues.

### Phase 5: Improve Architecture and Delivery

- [ ] Translate requirements into acceptance criteria.
- [ ] Understand cohesion, coupling, and separation of concerns.
- [ ] Design clear boundaries between application responsibilities.
- [ ] Handle concurrency and prevent duplicate operations.
- [ ] Measure performance and apply caching where justified.
- [ ] Deploy applications and manage environment configuration.
- [ ] Configure logs, monitoring, backups, and recovery.
- [ ] Maintain applications through refactoring and regression tests.

## Learning Approach

- Build one small feature at a time.
- Write acceptance criteria before implementation.
- Add tests as each feature develops.
- Explain implementation decisions in my own words.
- Use documentation and understand any AI-generated code.
- Record mistakes, fixes, and lessons learned.
- Revisit fundamentals throughout development.

AI engineering will follow a separate learning roadmap.
